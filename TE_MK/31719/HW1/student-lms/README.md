## Project Description

This project is a REST API for managing students.
It is built using Node.js, Express.js, Sequelize,
and SQLite.

The application allows users to create, retrieve,
update, and delete student records.

## Technologies Used

- Node.js
- Express.js
- Sequelize
- SQLite
- Postman

## API Endpoints

GET /students
- Get all students.

GET /student/:id
- Get a student by ID.

POST /student
- Create a new student.

PUT /students/:id
- Update an existing student.

DELETE /students/:id
- Delete a student by ID.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies:

   npm install

4. Start the server:

   node app.js

5. The server runs at:

   http://localhost:3000

## Testing

All API endpoints were tested using Postman.

The API returns JSON responses and uses
appropriate HTTP status codes.
